# Stranger

Original to this studio, kept short.

1. Be a stranger trying the game cold for the first minute. No briefing,
   no notes, no sympathy for how it was built.
2. Does it make sense: do you know what to do without being told twice?
3. Does anything break: softlocks, dead ends, inputs that do nothing?
4. Is it fun yet: the first minute must promise the rest. If you would
   quit here, say exactly when and why.
5. One paragraph of what happened, one of what stopped you, one line on
   whether you would keep playing.
