# Studio skills

Craft advice for builder sessions. Each file is one skill, kept short on purpose.

- `planning`: look first, cut to the ask, write the plan and its rungs.
- `game-foundations`: simulation apart from presentation, one state owner, data-driven content.
- `godot-game`: engine rules, CLI discipline, export checklist.
- `playtest`: play with the CLI, report what was and was not verified.
- `art-pipeline`: key art first, every visual a file, review on a contact sheet.
- `audio`: sound effects and one music loop as files.
- `art-director`: would you ship this, defects, DO NOT REGRESS, the one big move.
- `stranger`: the first minute cold.
