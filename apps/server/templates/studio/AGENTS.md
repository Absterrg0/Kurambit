# Studio skills

Craft advice, one skill per file, for the game's engine. A game's first
turn needs only what "The first turn" in its first message names.

- `godot-game`: Godot lane: engine rules, tool discipline, export checklist.
- `three`: three.js lane: first-turn rules, view recipes, the shell's rules, the Stage's Ask.
- `unity`: Unity lane: live editor tools, C# and Input System, probe, Linux and Windows builds.
- `art-pipeline`: the look locked in STYLE.json, characters by the person's route, generated art, Blender props and sprites.
- `audio`: sound effects and one music loop, from the library or synthesized.
- `playtest`: when to play, how with the game_explore tools, report what was and was not verified.
