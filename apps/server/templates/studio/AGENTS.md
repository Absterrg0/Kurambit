# Studio skills

Craft advice for builder sessions. Each file is one skill, kept short on purpose.
A game whose AGENTS.md has "The first turn" needs only what it names there.

- `planning`: look first, cut to the ask, write the plan.
- `game-foundations`: simulation apart from presentation, one state owner, data-driven content.
- `godot-game`: engine rules, tool discipline, export checklist.
- `three`: three.js browser lane: first-turn rules, view recipes, static project, studio bridge, export.
- `unity`: Unity lane: live editor tools, C# and Input System, probe, Linux and Windows builds.
- `playtest`: when to play, how with the game_explore tools, report what was and was not verified.
- `art-pipeline`: key art, the look locked in STYLE.json, characters and props from the library, Blender for what no pack has.
- `audio`: sound effects and one music loop, synthesized as files.
- `art-director`: would you ship this, defects, DO NOT REGRESS, the one big move.
- `stranger`: the first minute cold.
