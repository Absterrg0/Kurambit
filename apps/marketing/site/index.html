      Good to know

      When can I use Kurambit?

      We are letting people in small batches so every new studio gets a good first game. Join the waitlist and we will email you when your invite is ready.

      What do I need?

      A Linux x86_64 machine today and one signed-in coding agent: Codex, Claude Code, Cursor, Grok Build, OpenCode or Antigravity. Kurambit installs Godot and Blender for you.

      What does it cost?

      Kurambit is open source under the MIT license. It runs on the agent subscription you already have; one model is enough for the whole loop.

      Can it make any kind of game?

      Any genre. One brief aims for a game shaped like a Steam demo: something you can play, judge and keep improving with the studio.

      Is my game mine?

      Yes. Each game is its own git repository on your machine, with a normal Godot project and the Blender files that made its art. Open it without Kurambit any time.

      What happens to my email?

      It is stored privately and used only to contact you about Kurambit. It is never sold or shared, and you can ask to be removed at any time. Read the privacy note.
