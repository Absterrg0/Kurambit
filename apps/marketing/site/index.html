How it works

Every round, a real process.

Anyone can ask a model for a game. Kurambit runs the habits of a good team around it, every round, so a worse build never lands.

  1. 01

    Brief

    One or two sentences about the game you want. Genre, mood, art direction.

  2. 02

    Build

    Your agent writes the Godot project and models assets in Blender. Every source stays editable.

  3. 03

    Play

    A separate tester session plays each build and reports what it actually saw.

  4. 04

    Judge

    Two builds, compared blind. Ties and worse builds are reverted, never merged.

FAQ

Questions.

When can I use Kurambit?

We're letting people in small batches so every new studio gets a good first game. Join the waitlist and we'll email you when your invite is ready.

What do I need?

A Linux x86_64 machine today and one signed-in coding agent. Kurambit installs Godot and Blender for you, and your games export to Windows, Linux and the web.

What does it cost?

Kurambit is open source under the MIT license. It runs on the agent subscription you already have; one model is enough for the whole loop.

Do I own what it makes?

Yes. Every game is its own git repository with editable sources, scripts and .blend files. Take it anywhere.

What happens to my email?

It's stored privately and only used to contact you about Kurambit. Never sold or shared, and you can ask to be removed any time. Privacy note.
