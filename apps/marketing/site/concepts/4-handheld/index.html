Spec sheet

Everything that happens between your sentence and a game you can play.

01 / input
One sentence
“a small game about a beekeeper guarding hives through a storm”
02 / engine
Godot 4.7
Native 2D and 3D. three.js for quick browser games.
03 / assets
Blender 4.5
Every model keeps its .blend and the script that made it.
04 / playtest
Every build
A separate tester session plays it for real.
05 / judge
Blind A/B
Ties and worse builds are reverted, never merged.
06 / output
.exe · linux · web
Export when it feels right.
07 / agents
Bring yours
Codex, Claude Code, Cursor, Grok Build, OpenCode, Antigravity.
