Manifesto

  1. 01

    The model builds.

    Your coding agent writes the engine project and models assets in Blender. You write one sentence.

  2. 02

    The tester plays.

    A separate session plays every build and reports what it actually saw. Screenshots are not proof.

  3. 03

    The judge is blind.

    Two builds, no labels. The better one wins. Ties lose.

  4. 04

    Worse never ships.

    A build that does not beat the last one is reverted. Every round, without exceptions.

  5. 05

    You keep the files.

    Each game is its own git repository. .blend sources, scripts, exports. Leave any time.

  6. 06

    Any agent. Any genre.

    Codex, Claude Code, Cursor, Grok Build, OpenCode, Antigravity. Platformer to roguelite.
