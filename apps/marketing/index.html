The loop

Not a prompt box. A studio with a process.

Anyone can ask a model for a game. Kurambit wraps the model in the habits of a real team, and runs them every round so a weak build never ships.

  1. 01

    Brief

    A name, a genre, an art direction. One paragraph is enough to start.

  2. 02

    Build

    Your agent writes the engine project and models assets in Blender, keeping every source editable.

  3. 03

    Play

    A separate tester session plays each build and reports what it actually saw, not what it hoped.

  4. 04

    Judge

    Builds are compared blind. A tie or a worse build is reverted, never merged.

  5. 05

    Keep going

    Rounds continue until the budget ends, leaving a game shaped like a Steam demo for you to polish.

Real tools, real files

Everything it makes, you can open.

Godot 4.7

Native games with scenes and scripts you can open in the editor. Kurambit installs a pinned, checksum-verified copy for you.

Blender 4.5 LTS

Every model keeps its .blend source and the script that made it, next to the engine-ready export.

three.js

A quick browser lane for small ideas you want to play and share in minutes.

Play and export

Play the real build inside the app, ask for changes in plain words, and export Windows, Linux and web builds.

Every game is its own git repository. Move it, fork it, or keep working without Kurambit.

Bring your own agent

No new subscription. Use what you have.

Kurambit drives the agent you already sign in to. One model is enough for the whole loop; add more only if you want a second opinion.
