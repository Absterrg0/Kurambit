# Open source licenses

Kurambit includes third-party software and adapted assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → General**, find **Open source licenses** under **About**,
  and select **View licenses**.
- On mobile, open **Settings → About Kurambit → Open source licenses**.

The page lists the version when available, license identifier, and the parts of Kurambit that include
or use the item. This also covers optional device tools that Kurambit installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.
