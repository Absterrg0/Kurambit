# Welcome wizard

Kurambit shows setup when you open a new installation. Existing workspaces skip it.

## Connect

Kurambit runs your agents and game tools on this computer. Continue once the local connection is ready.

If setup cannot confirm the workspace during startup, select **Reload** to try again. If it cannot read your saved settings, select **Retry** after storage becomes available.

## Agents

Connect the agent that will build your games. Setup always checks for Codex and Claude, and on a new installation it also turns on OpenCode, Grok, Pi or Muse when their command-line tool is already installed. If Codex or Claude needs installation or sign-in, use its setup action; fix any other agent in **Settings > Providers**, where you can also add agents later. An agent you turn off stays off.

Select **Start making games** to finish setup and open the Games home. Use **New game** to describe a game for your agent, or **Open game** to select an existing game folder containing `game.json`.
