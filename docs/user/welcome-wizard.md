# Welcome wizard

Game Studio shows setup when you open a new installation. Existing workspaces skip it.

## Connect

Game Studio runs your agents, Blender, and Godot on this computer. Continue once the local connection is ready.

If setup cannot confirm the workspace during startup, select **Reload** to try again. If it cannot read your saved settings, select **Retry** after storage becomes available.

## Agents

Connect the agent that will build your games. Setup checks for Codex and Claude. If one needs installation or sign-in, use its setup action and follow the instructions. You can add other providers later in **Settings > Providers**.

Select **Start making games** to finish setup and open the Games home. Use **New game** to describe a game for your agent, or **Open game** to select an existing game folder containing `game.json`.
